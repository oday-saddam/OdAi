# odAi

نسخة نهائية مفككة من التطبيق.

## الملفات

- `index.html`: الهيكل وواجهة التطبيق.
- `css/style.css`: التصميم المتجاوب والأنماط.
- `js/app.js`: منطق التطبيق والاتصال بـ OpenRouter.
- `manifest.webmanifest` و`sw.js` وأيقونات PWA: التثبيت والتخزين المؤقت.

## التشغيل

ارفع كل الملفات كما هي إلى الاستضافة نفسها، ثم افتح `index.html` من رابط HTTPS. لا تفتح الملف من `file://` أو `content://` إذا أردت التخزين والتثبيت والقفل.

مفتاح OpenRouter يُدخل من داخل الإعدادات ويُحفظ محلياً في المتصفح فقط. لا تضع المفتاح داخل أي ملف أو مستودع.
